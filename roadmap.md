## New Functionality - 25.05.2026

AI daily workout recommendation based on the past 7 days of run/bike efforts.

Implementation plan:

- User selects `<20 min`, `20-40 min`, or `40+ min` duration (`20-40 min` by default).
- User selects easy, moderate, or hard effort (moderate by default).
- User selects run or bike workout.
- Recommendation is generated by a Foundry `daily-recommendation` agent using the past 7 days of run/bike efforts, current load, readiness, recent hard-session frequency, and training streaks.
- Safety guardrails can downgrade selected effort or duration when recent training or readiness makes the requested option risky.
- If today's planned session exists, the recommendation is shown as contextual guidance rather than automatically replacing the plan.
- First version computes on demand and does not persist accepted/skipped recommendations.
